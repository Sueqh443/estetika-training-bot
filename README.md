# Эстэтика Стиля · Обучение

Готовый исходный код Telegram-бота, программа обучения и 20 изображений PNG.

- 6 модулей по 6 страниц; текст перенесён из предоставленных видео и скриншотов.
- Навигация «Назад / Далее / В меню» и отметки завершённых модулей.
- После всех модулей открывается тест из 10 вопросов с кнопками A–F.
- После любых десяти ответов появляется один и тот же экран «Вы справились! Напишите своему менеджеру».
- Баллы и статус «сдал / не сдал» не показываются. Уведомлений менеджерам нет.
- Прогресс и выбранные ответы сохраняются в локальной базе SQLite. Перезапуск не сбрасывает обучение.

Бот ещё не подключён к Telegram: для запуска нужен токен вашего бота. В архиве нет чужих токенов или аккаунтов.

## Быстрый запуск на Windows

1. Создайте бота в официальном [@BotFather](https://t.me/BotFather): команда `/newbot`, затем имя и свободное имя пользователя, заканчивающееся на `bot`.
2. Распакуйте архив целиком. Установите Python 3.11 или новее с python.org, если его ещё нет.
3. Скопируйте `.env.example` в файл `.env` и замените `PASTE_TOKEN_HERE` вашим токеном. Открывайте файл обычным Блокнотом. Токен держите у себя.
4. Откройте `start_windows.bat`. Первый запуск установит зависимости.
5. В Telegram откройте своего бота и нажмите «Запустить» или отправьте `/start`.
6. Загрузите `assets/logo.png` как аватарку через BotFather → `/mybots` → ваш бот → Edit Bot → Edit Botpic.

Имя бота: `Эстэтика Стиля | Обучение`.
Описание: `Обучение работе в «Эстэтике Стиля»: шесть модулей, практические ситуации и итоговый тест.`

Окно программы должно оставаться открытым. Для работы круглосуточно используйте запуск на VPS ниже.

## Работа круглосуточно на VPS

При установленном Docker с Compose:

1. Скопируйте папку проекта на сервер.
2. Создайте файл `.env` из `.env.example`, укажите `BOT_TOKEN`.
3. В папке выполните `docker compose up -d --build`.

Бот сам запустится после перезагрузки сервера. Входящие порты, домен и SSL не требуются: используется polling. Серверу нужен исходящий HTTPS-доступ к Telegram API.

Команды:

```bash
docker compose logs --tail=50 bot
docker compose restart bot
docker compose down
```

Не запускайте одновременно две копии с одним токеном. База при Docker-запуске находится в `progress/progress.sqlite3`. Сохраняйте всю папку `progress` при переносе. Для согласованной резервной копии сначала остановите контейнер; затем скопируйте папку и снова запустите его.

## Что внутри

- `bot.py` — Telegram, кнопки и обработка нажатий.
- `core.py` — переходы, формирование экранов и сохранение прогресса.
- `data/course.json` — тексты всех 36 страниц и 10 вопросов.
- `assets/` — логотип, приветствие, 6 модулей, вступление к тесту, 10 вопросов, завершение.
- `preview.html` — просмотр всех материалов в браузере без запуска бота.
- `test_bot.py` — проверка переходов и сохранения прогресса.

Текст урока отправляется обычным Telegram-сообщением сразу под изображением. Это сохраняет читаемость и позволяет показывать длинные страницы целиком, без ограничения подписи к фото. При переходе обновляется текущая пара сообщений.

Чтобы поменять материалы, отредактируйте `data/course.json` и/или замените PNG в `assets`, затем перезапустите бота. Если меняете структуру или число уроков, заранее предусмотрите перенос сохранённого прогресса.

Ссылка на конкретного менеджера не установлена: финальный текст предлагает написать тому менеджеру, с которым кандидат уже общался, как в примере.

## Проверка

```bash
python -m unittest -v test_bot.py
```

Проверяются все страницы, блокировка теста до завершения уроков, сохранение прогресса после перезапуска и одинаковый финал при разных ответах. Живое подключение к Telegram требует вашего токена и проверяется после запуска.
